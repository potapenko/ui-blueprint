## Outcome

Establish how to obtain bounded DOM/AX/layout observations, preserve exact
target/document/frame identity and isolate delivery from verified outcome on a
task-owned Web fixture. Compare the relevant pinned code from agent-browser,
browser-use, Playwright injected/backend/session owners and Stagehand; consult
current primary CDP/CSSOM/ARIA docs for actual APIs selected. Do not treat a
Chromium mechanism as evidence of Safari support. Record real support limits.

Return a compact source-reading ledger, a proposed adapter boundary, and one
bounded runnable prototype covering a concrete uncertainty: repeated labels,
frame/remount identity or DOM/AX geometry mapping. Show independent expected vs
observed values, not a collector that simply approves its own output.
Any live observation is from a new isolated owned fixture. Capture source states,
coverage, unavailable properties and relevant time/environment accurately.
Do not execute a real application's actions or attach an existing logged-in tab.
