## Mandatory design criteria

1. Enforce the claimed Rust allocation metric before relevant allocation, including
   decode/reject/validate/replay/encode overlaps and allocator failure semantics.
   Distinguish actual usage, reservations, retained layout, OS/SDK/stack/RSS and
   conservative realloc accounting. No fake permit, postparse enforcement,
   allocator unwind/recursive logging or false recoverable infallible OOM.
2. Each proposed pool/quota/handle has a feasible owner and lifetime. Aggregate
   retained grants cannot be copied/released early across workers; child ledger
   and parent roots must count once, actual live bytes remain covered. Check that
   the proposed numeric pool inventory is internally feasible under its own limits.
3. Complete, correlated canonical channel data survives later worker/channel
   failure. Publication/ACK/partial-frame/cancel ordering is defined; parent must
   not secretly reparse outside its claimed budget. Caller-held completions remain
   owned/charged and cannot unnecessarily serialize independent sessions.
4. Deadline/cancel/late callbacks, registered helper ownership, loss of parent/worker,
   process cleanup and quarantine have finite actionable semantics. No resource or
   capture grant reuse before actual cleanup. Preserve independent Target progress,
   known permission refusals and real application ownership.
5. Future mutation dispatch has parent-held redacted possible-effect state before
   potential delivery; uncertain outcome never retries or invents rollback. Do not
   require live action implementation from this design-only packet.
6. Reusable explicit-request sessions preserve local model-free/static boundaries;
   no obligatory worker launch per measurement, UI polling, new graph/parser or
   unregistered D02/core schema changes. Existing K01 behavior remains protected
   except the exact proposed subordinate-grant delta.
7. Proposed contract deltas and source owners are explicit; required implementation
   evidence is falsifiable and scoped. Missing future runtime proof must remain a
   gate, not a defect solely because this artifact is a proposal. Flag a concrete
   internal contradiction or unimplementable preservation claim, not speculative
   alternatives or optional architecture preferences.
