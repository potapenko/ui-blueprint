## Acceptance и checks

Каждый новый spec node ≤100 физических строк; stable clause IDs/revisions,
read_when/do_not_read_when, явные зависимости и inverse map к разделам исходников.
Отдельно от обязательных норм сохранить будущие этапы и каталоги; они не теряются
и не подгружаются в каждый пакет. Routes R01/R02/R03 и дальнейших доменов однозначны.
Нормы не сокращаются до общих лозунгов и не дублируют глобальный workflow.
Проверить локальные file/anchor links, completeness/source mapping, stale Draft
assertions, изменённые coordination links, `git diff --check`; Rust tests не нужны.
Никакая бумажная проверка не объявляется runtime acceptance или independent review.

## Git и завершение

Exclusive Git lease предоставляется вместе с dispatch; root может параллельно
писать только disjoint coordination metadata без stage/commit.
Stage/commit только разрешённые собственные файлы; перед commit проверить index
и чужие изменения. Не включать root coordination edits, если они появились.
Checkpoint в master обязателен. Не продолжать R01/R02/R03 самостоятельно.
В receipt указать contract closure, выполненные проверки, changed paths, residual,
путь новой root/mapping, компактные маршруты для R01/R02/R03 и next dependency.
Финальный ответ — terminal receipt по [шаблону](../packets.md).
Root сам прочитает финальный ответ; не требуется писать другим чатам.
