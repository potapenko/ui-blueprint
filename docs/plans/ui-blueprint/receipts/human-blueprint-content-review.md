## Narrow primary-source research

- [NN/G — Visual Hierarchy](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/): hierarchy should express intended importance through scale and grouping. Application: let the complete form and useful measurements dominate; group small provenance separately. This is a communication principle, not a mandate for additional UI colors.
- [NN/G — Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/): specialized secondary material belongs behind a clear second level. Applied by analogy to a static document: overview plus clearly named details and retained machine appendix, rather than displaying all metadata on the main sheet. Do not hide the meaningful form itself.
- [Onshape — Drawing Dimensions](https://cad.onshape.com/help/Content/Drawing/drawing_dimensions.htm): dimensions associate with selected entities; crowded extensions/text can be repositioned. Application: explicit source anchors and separated readable labels. Do not import manufacturing symbols or tolerance assumptions.
- [Onshape — Units and Precision](https://cad.onshape.com/help/Content/Drawing/drawing_properties_-_units_and_precision.htm): display precision, drawing units and tolerance precision have separate controls. Application: human label precision is a presentation decision distinct from source numerical truth. Our source units remain CSS px; no Onshape defaults become product requirements.
