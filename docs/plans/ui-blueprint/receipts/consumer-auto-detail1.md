## Proposed bounded implementation — not executed

Recommend one conservative Evolve rule: retain a qualifying final automatic chunk
only in the already-complete G01 and machine package, without an extra D sheet.
Do not merge it into a full preceding detail: Email D02 would become13 and exceed
the automatic cap12. Do not raise density, remove nodes before chunking, rebalance
other chunks, or delete a prompt file while leaving its sheet/manifest entry.

Minimum initial eligibility, all conditions required:

1. Single observed Document view, no explicit detail requests anywhere. Existing
   auto-density branch only; final nonempty chunk smaller than the unchanged cap,
   with earlier full chunks retained. Proposed/detail/compare/flow and multi-view
   behavior stay unchanged. Any explicit request, including this same N024, keeps
   the existing plan even when it has zero dimensions.
2. Every member has known native DIV role, no semantic role or label, no parent,
   children, declarations, extensions or state/action record. Its only properties
   are the three requested public geometry fields, all Unknown. Any extra property
   or other availability/role conservatively retains the sheet. In particular,
   known geometry including zero sizes, public text/name, states including false,
   control roles, redacted content and unsupported content are not this case.
3. No member participates in a relation, mapping, focus binding or required
   dimension/anchor context. Preserve the existing flat unknown-only source facts;
   do not infer lack of interaction from DIV. For the narrow observed geometry-only
   case, unavailable frames yield no known measurement; this must also be proved
   by unchanged required IDs/owners in the candidate's focused verification.
4. G01 keeps every original component, literal caller context, unknown caveats,
   source exclusions and reference-visible content. Scene/dimensions and source
   input bytes remain exact. No free-text parsing invents a caller-to-node binding.
   The rule only avoids a redundant automatic enlargement; it does not classify
   the record as empty or invisible, or weaken what the overview must depict.

This is deliberately narrower than a general usefulness classifier. Zero assigned
dimensions alone is insufficient: an explicit AX/text/state fragment or a known
clipped frame remains useful without selected measurements. Register D03 fails

both DIVs. Retain an unknown-only chunk if any protection above is uncertain.
