## Test behavior

`every_manifest_engine_expectation_is_verified_at_its_contract_layer` reads the
actual authored manifest and every declared file through AnalysisDocument::from_json.
It checks explicit boolean/label fields, unique paths constrained to the fixture
directory and rejects unsupported engine expectation labels without skipping.

- match: canonical contract-valid result must verify with Ok(()).
- mismatch: canonical contract-valid result must return ResultMismatch, not an
  unrelated parser/contract failure treated as successful negative verification.
- not_checked: contract-invalid input must reject at the parser/validation layer;
  valid query/evaluation artifacts must yield NotAResult. Valid result artifacts
  cannot use this label to evade computation.

All cases are visited before aggregate result assertions, so one bad fixture does
not hide later cases. Both successful and tampered recomputation must be present.
No values/expectations are generated by engine, and fixture evidence is not edited.
