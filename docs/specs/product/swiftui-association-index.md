# Separate bounded association index

- Node type: leaf; domain: `uib.swiftui-debug-capture.association-index`.
- Contract: `UIB.SWIFTUI-ASSOCIATION-INDEX@1`; Authority: Active; Stability: Evolving.
- Authority: the operator's approved S13 repair and explicit continuation through
  the real unchanged Random dialog on2026-11-23. This selects a bounded technical
  acquisition policy; it does not qualify runtime acceptance or another target.
- Requires: [debug capture](swiftui-debug-capture.md), [PRIVACY@1](privacy.md),
  [IDENTITY@1](identity.md), [LIFECYCLE@1](lifecycle.md).

## INDEX.UNITS

The recorded TreeData association index is not a traversal of a selected UI tree.
Its entries contain subgraph identities and element/model references only. Actual
source evidence shows recorded children can be sibling dependency subgraphs, and
recorded parent attachments can differ from dependency-parent links. A direct-
children substitute is therefore incomplete and must not replace the recorded tree.

The real S13 request refused the old1024 global-index cardinality guard before
component selection. An owned stress fixture reproduces this with3090association
owners/3093subgraphs while its requested dialog has39geometry nodes. This change
explicitly raises only that metadata-index admission guard from1024 to8192 owners,
subgraphs and per-owner link pairs. It does not silently redefine the old guard
or claim that an addressed lookup alone resolved child completeness.

## INDEX.BOUNDS

Keep the existing2MiB cumulative source-read ceiling,10s acquisition deadline,
256emitted-node/depth and1024 selected/discovery raw-tree bounds. Source reads and
fixed calls still consume their existing budgets. Large index input that cannot
finish within them refuses; no retry, deadline increase or automatic scope expansion.
Index count/capacity and pointer arithmetic remain bounded before loops/reads.
Collect no outside position/size, model values, text, environment or geometry.
Index records are observation-owned and never persisted as raw addresses.

Each referenced selected raw record still requires graph/page ownership and model
exclusion before geometry. Every read from index preparation remains in the audit;
protected ranges discovered later must be checked against that complete history.
The audit may count overlaps using sorted start/end endpoints: for each read
[a,b), count private starts<b minus ends<=a. Preserve duplicate/nested intervals
and the original strict-boundary result; never sample or omit earlier reads.
No AG getter, model evaluation, graph update or metadata sorting call is added.
Existing recorded child ordering/parent association and canonical formats remain.

## INDEX.ACCEPT

Required: reproduce old refusal on a large unrelated index, then obtain the same
small source dialog without collecting the unrelated views, within all unchanged
read/time/output bounds; preserve actual model-read exclusion. Reject8193 entries,
corrupt/cyclic maps, malformed pointers and actual byte/deadline exhaustion.
Qualify on the unchanged consumer after review. This is an explicit metadata
policy evolution under the repair outcome, not a blanket quota increase or a
claim of complete application coverage.
