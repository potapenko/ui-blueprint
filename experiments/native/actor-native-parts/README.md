# S03 native-overlay experiment

This is a fixture-only candidate owned by S03 chat
`01a20923-023c-7cd0-8421-a2e20177df71`. It has no product admission, installed CLI
entry or release claim. Shared collector integration belongs to S13. See the
[S03 state](../../../docs/plans/ui-blueprint/receipts/s03-actor-picker.md).

The unchanged donor already uses an actionless native cursor overlay on rows.
The [owned fixture](../../../tests/bridges/native/SwiftUIActorScopeFixture.swift)
reproduces that platform boundary with `UIB_ACTOR_SOURCE_SHAPE=1` and
`UIB_ACTOR_CURSOR=1`. Compile with `ACTOR_NO_ORACLE` to remove the geometry
observers themselves. This is not donor instrumentation or copied product data.

`select_parts.py` indexes structural layoutComputer references once per native
subgraph, proves each native witness, follows its recorded ancestry, and selects
all nearest overlay boundaries inside the requested source container and body
owner. It never chooses a row by traversal index, text or coordinates. A toggle
outside the list is excluded; multiple owners, stale/incomplete bindings, cycles
and limits refuse. Cached structural headers share the1024-record discovery
budget. The normal selected walk and transform context are charged additionally.
Existing byte, call, output, depth, privacy and lifecycle limits remain in force.

Run pure scope checks:

```sh
python3 -B experiments/native/actor-native-parts/check_selection.py
```

`capture_fixture.capture(debugger, request, bundle, output)` is a temporary LLDB
entry over pinned existing collector modules. Load their exact directory on
`sys.path` first. The trusted request supplies the freshly verified fixture PID,
birth and selected window. The harness accepts only its exact synthetic bundle
and scope, preserves the existing admission gate, and restores Python hooks on
exit. Never point it at a product process or rename a donor to pass its gate.
Use the ordinary retained-debugger recovery protocol on uncertain failure.

Outputs remain outside the repository under the operator's storage policy.
Require a terminal ready manifest and restored detach before using its Snapshot
and `native-parts-selection.json`. Keep the original canonical bytes; do not
rewrite transforms or paste hand-authored frames into them.

Current evidence: four mounted row boundaries and their Text nodes are collected
within the original limits on a20-option synthetic form without oracle modifiers.
Row overlay geometry has qualified root translations. The label-side transform
is dirty and remains unknown. This experiment neither evaluates that transform
nor substitutes its parent's mapping. It does not prove full list coverage,
actor-ID correspondence, native-image mapping or the real Actors acceptance case.
